03 — Consideraciones

Precios referenciales. Cada estudio contable tiene necesidades distintas. Si requiere menos funcionalidades del nivel indicado, el valor puede ajustarse. Si desea agregar o combinar módulos, se cotiza tomando el nivel Completo como base mínima.

Configuración personalizada incluida. El sistema se configura con el nombre del estudio, servicios ofrecidos, precios y flujos de atención específicos. No es una solución genérica.

Tiempo de entrega. Nivel Básico: 2 a 3 semanas. Nivel Completo: 3 a 4 semanas. Nivel Personalizado: según alcance acordado.
